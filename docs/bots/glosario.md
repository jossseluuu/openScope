# Glosario

| Término | Significado |
|---|---|
| **ACAS / TCAS** | Sistema anticolisión a bordo. Da avisos de tráfico (TA) y de resolución (RA); el piloto obedece el RA por encima del control |
| **AGL / MSL** | Altura sobre el terreno / altitud sobre el nivel del mar |
| **AIRAC** | Ciclo de 28 días en el que se actualiza la información aeronáutica oficial |
| **AIP** | Publicación de Información Aeronáutica de cada país (en España, ENAIRE) |
| **AMAN / DMAN** | Gestor de llegadas / de salidas: calcula la secuencia y los tiempos |
| **CD&R** | Detección y resolución de conflictos (*conflict detection and resolution*) |
| **CMA-ES** | Algoritmo evolutivo con el que se ajustan los parámetros del Bot A |
| **DAgger** | Imitación iterativa: la red vuela, el maestro (Bot A) corrige lo que haría en esas situaciones y se reentrena |
| **DH / MDA** | Altura de decisión / altitud mínima de descenso de una aproximación |
| **Escudo de seguridad** | Capa común a los bots que prohíbe acciones peligrosas e impone las obligatorias |
| **FAF** | Fijo de aproximación final |
| **FCFS** | Primero en llegar, primero en ser servido |
| **Features** | Números con los que se describe la observación a la red del Bot B (versión 8) |
| **FL** | Nivel de vuelo, en centenas de pies de altitud de presión |
| **ILS / localizador / senda** | Sistema de aterrizaje por instrumentos: guiado lateral (localizador) y vertical (senda de planeo) |
| **LVP** | Procedimientos de baja visibilidad |
| **Máscara de acciones** | Lista de acciones permitidas para una aeronave en un momento dado |
| **MVA / MSA** | Altitud mínima de vectorización / altitud mínima de sector |
| **ONNX** | Formato del modelo entrenado que ejecuta el navegador |
| **PPO** | Algoritmo de aprendizaje por refuerzo usado para el Bot B |
| **RECAT-EU** | Categorías europeas de estela turbulenta (A a F) |
| **Rulebook** | Conjunto de reglas con nivel y referencia normativa (`realism/Rulebook.js`) |
| **SID / STAR** | Salida / llegada normalizada por instrumentos |
| **STCA** | Alerta de conflicto a corto plazo en tierra, para el controlador |
| **Tier** | Nivel de una regla: 0 seguridad, 1 separación, 2 procedimiento, 3 eficiencia, 4 entorno |
| **VNAV / HOLD** | Modo vertical que sigue el perfil del procedimiento / que va directo al nivel autorizado |
| **What-if** | Simular una maniobra antes de darla para comprobar que separa y no crea otro conflicto |
